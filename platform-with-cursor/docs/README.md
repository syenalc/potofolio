# ドキュメント一覧

このディレクトリには、プロジェクトに関する各種ドキュメントが格納されています。

---

## 📄 ドキュメント一覧

### [要件定義書](./requirements.md)
プロジェクトの要件定義を記載したドキュメントです。
- プロジェクト概要
- 機能要件
- 技術要件
- 画面遷移フロー

### [進捗管理](./PROGRESS.md)
プロジェクトの進捗状況を管理するドキュメントです。
- フェーズ別の進捗状況
- タスクのチェックリスト
- マイルストーン
- 完了したタスクの記録

### [技術スタック](./TECH_STACK.md)
プロジェクトで使用する技術スタックの詳細を記載したドキュメントです。
- 使用するフレームワーク・ライブラリ
- 依存関係
- プロジェクト構造
- 参考リソース

---

## 📝 ドキュメントの更新について

各ドキュメントは、プロジェクトの進行に合わせて随時更新してください。

特に以下のタイミングで更新することを推奨します：
- **要件定義書**: 要件が変更された場合
- **進捗管理**: タスクが完了した場合、または新しいタスクが追加された場合
- **技術スタック**: 新しい技術を導入した場合、または依存関係が変更された場合
