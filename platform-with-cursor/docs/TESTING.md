## テスト実行方法

1. 開発サーバーを起動: `npm run dev`
2. 各ページを順番に確認
3. ブラウザの開発者ツールでエラーを確認
4. Lighthouseでパフォーマンススコアを確認
5. レスポンシブデザインをDevToolsで確認
