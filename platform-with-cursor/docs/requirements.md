# 動画配信プラットフォーム 要件定義書

## プロジェクト概要
Udemyクローンのような動画配信プラットフォームのデモ版を作成します。月学生（ユーザー）が配信する動画を閲覧できるプラットフォームです。

## 基本方針
- **認証機能**: なし（デモ版のため後回し）
- **決済機能**: なし（デモ版のため後回し）
- **動画配信**: 誰でも無料で視聴可能
- **動画形式**: YouTube埋め込み形式を使用

## 機能要件

### 1. トップページ（コース一覧ページ）
- **目的**: 利用可能なコースを一覧表示する
- **機能**:
  - 複数のコースをカード形式またはグリッド形式で表示
  - 各コースカードには以下の情報を表示:
    - コースタイトル
    - コース画像/サムネイル
    - コースの概要（簡易版）
  - コースカードをクリックすると、コース詳細ページに遷移

### 2. コース詳細ページ
- **目的**: 選択したコースの詳細情報を表示する
- **機能**:
  - コースの詳細情報を表示:
    - コースタイトル
    - コース説明
    - コース画像/サムネイル
    - セクション数、動画数などの統計情報
  - 「コースを見る」ボタンを配置
  - 「コースを見る」ボタンをクリックすると、動画視聴ページに遷移

### 3. 動画視聴ページ
- **目的**: セクションごとに分かれた動画を視聴する
- **機能**:
  - **レイアウト**: Udemyのような2カラムレイアウト
    - 左側: 動画プレーヤー（YouTube埋め込み）
    - 右側: セクション・動画リスト
  - **セクション機能**:
    - コースをセクションごとに分割して表示
    - 各セクションには複数の動画が含まれる
    - セクションは折りたたみ可能
  - **動画リスト機能**:
    - 各動画のタイトルを表示
    - 現在視聴中の動画をハイライト表示
    - 視聴済みの動画にチェックマークなどの視覚的インジケーターを表示
  - **連続視聴機能**:
    - 一つの動画を見終わったら、自動的に次の動画に進む機能
    - または「次の動画」ボタンで手動で次の動画に進む機能
  - **動画プレーヤー機能**:
    - YouTube埋め込みプレーヤーを使用
    - 動画リストから動画をクリックすると、該当する動画を再生

## 技術要件

### フロントエンド
- Next.js（既存プロジェクト構成を利用）
- React
- TypeScript

### 動画配信
- YouTube埋め込みAPIを使用
- 各動画はYouTubeの動画IDで管理

### データ管理
- コース情報、セクション情報、動画情報は静的データまたはJSONファイルで管理（デモ版のため）

## 画面遷移フロー

```
トップページ（コース一覧）
    ↓ [コースカードをクリック]
コース詳細ページ
    ↓ [「コースを見る」ボタンをクリック]
動画視聴ページ
    ↓ [動画リストから動画を選択]
動画プレーヤーで動画再生
```
